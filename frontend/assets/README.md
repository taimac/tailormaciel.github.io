# Assets

This folder contains static resources such as images, fonts, and icons.

## Purpose

- Stores all non-code files needed by the frontend.

## Best Practices

- Optimize images for web (compression, correct formats).
- Use SVGs for icons when possible.
- Organize assets by type or feature.

## Security Considerations

- Do not store sensitive data in assets.
- Ensure assets do not include executable code.
