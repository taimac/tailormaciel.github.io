# Styles

This folder contains all CSS files for the frontend.

## Purpose

- Implements the visual design using BEM methodology and responsive design principles.

## Architecture

- Supports the **Presentation Layer**.
- Organize styles by component or feature for maintainability.

## Best Practices

- Use CSS variables for theming.
- Follow BEM naming for clarity.
- Optimize for performance and accessibility.

## Testing Strategy

- Use visual regression testing tools (optional).
- Manually verify styles in different browsers and devices.
